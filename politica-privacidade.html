Política de Privacidade

1. Coleta de Dados

Coletamos informações fornecidas pelo usuário apenas para fins de atendimento e análise de crédito.

2. Uso das Informações

Os dados são utilizados exclusivamente para contato, simulação e encaminhamento de serviços financeiros.

3. Proteção de Dados

Adotamos medidas de segurança para proteger suas informações conforme a LGPD (Lei Geral de Proteção de Dados).

4. Compartilhamento

Não vendemos ou compartilhamos dados pessoais sem consentimento do usuário.
